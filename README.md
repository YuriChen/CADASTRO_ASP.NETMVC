📋 Sobre o Projeto

Este projeto foi desenvolvido como parte de um teste técnico para uma vaga de desenvolvedor Full Stack. O sistema consiste em uma aplicação web para gestão de clientes e seus beneficiários, utilizando ASP.NET MVC 5 com arquitetura em camadas (DAL/BLL).
🚀 Funcionalidades Implementadas
Clientes

    ✅ CRUD completo de clientes

    ✅ Validação e formatação de CPF (com máscara e validação de dígito verificador)

    ✅ Impedir CPFs duplicados no banco de dados

    ✅ Campos obrigatórios com validação client-side e server-side

Beneficiários

    ✅ Cadastro de múltiplos beneficiários por cliente

    ✅ Popup com formulário para inclusão de beneficiários

    ✅ Validação de CPF do beneficiário (formato e dígito)

    ✅ Impedir CPF duplicado para o mesmo cliente

    ✅ Grid com jTable para listagem, edição e exclusão de beneficiários

    ✅ Temas customizáveis para o grid (jTable)
